# Explanations for the above Classroom Suggestions





1. Work from bell to bell on curricular topics, preferably Robotics. Maximizing time on task is key to success.
2. I encourage the productive use of cell phones for learning. Maintaining focus on the topic during and after class is the most important variable.
3. If you need to use your cell phone for an important reason, stand up. This shows you're proud of what you're doing and ensures transparency.
4. The top grade for the course will range between 86%-100% and will be determined by the industry’s need for soft skills (learning collaboratively, not cheating). If you can complete an assignment, help at least three others. I would rather see 10 students collaboratively achieving 100% in the course than three students competitively scoring 86%.
5. Use "my" (CamelCase formatting) in front of your variable and function names. This helps us identify custom code and prevents unnecessary Googling.
6. Tools like ChatGPT can explain code for you. To save time, I do not heavily comment my code.
7. Learn VIDEO-FLAC for coding comfort: Variables, Input/Output, Decisions, Events, Objects – Functions, Loops, Arrays, Classes.
8. My coding course link is available at GitHub: High School JavaScript Game Dev Assignments.
9. To reduce hardware challenges, I will teach one or more assignments per class. However, I encourage students to work ahead to ensure the assignments function correctly (i.e., are not deprecated).
10. If you finish all assignments early, you will have more time to focus on your final project.
11. I divide Robotics into the following areas: coding, sensing, actuators, IoT, and Machine Learning.
12. To pass the course, you must complete a Level 1 individual final project. This should connect a sensor with an actuator of your choice and interest.
13. To earn an "A," your Level 2 individual final project should integrate multiple sensors, actuators, IoT, and/or Machine Learning. All projects must include coding.
14. If you finish early, you can contribute to a Level 3 group final project. For these, we expect students with machine learning projects to collaborate with those working on IoT and/or multiple sensor-actuator projects. Each group member should contribute a unique skill to the team. Yes, soft skills are a skill—teamwork, communication, problem-solving, adaptability, and time management.
